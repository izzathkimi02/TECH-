CANE TECH STUDENT COMPANY WEBSITE

1. Open index.html in a browser to view the website.
2. For publishing online, upload index.html and the assets folder to a static web hosting service (e.g., GitHub Pages or Netlify).
3. Replace all sample and placeholder data before submitting:
   - Actual company address and Google Maps embed/link
   - Group member names, number of members, roles and photos
   - Contact phone and email
   - Product/service claims and exact features approved by your group
   - Logo presentation (a sample generated logo is stored under assets/)
4. To enable the email form, edit COMPANY_EMAIL near the end of index.html. It opens a visitor's email application and is NOT a server-side contact form.
5. This website is a proposed smart walking cane / assistive technology company concept, not verified facts about an existing business.

The site is responsive for mobile and desktop, and uses Google Fonts with system-font fallbacks.
